1: What would happen if an ArrayList was used instead of a HashSet? Is there an advantage to using a HashSet here?
If we were to use an ArrayList instead of a HashSet, we would be able to store any number of duplicate movies, as well as keep track of what order the movies are given. This might matter if you want to know how many times a person has watched a movie, what their most watched movie is, or what movie they watched first or most recently. However, using an ArrayList instead of a HashSet would slow down accessing specific movies that someone has watched, because you would have to traverse through the entire ArrayList, which takes O(n) time, rather than the time of O(1) that it would take to access the same information from a HashSet.
